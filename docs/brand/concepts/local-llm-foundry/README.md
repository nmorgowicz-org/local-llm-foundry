# Local LLM Foundry branding options

These are exploratory branding assets for the repository and its GitHub Social
preview.

## Directories

- `hero-options/` — original high-resolution PNG concepts for editing.
- `social-ready/` — 1280px-wide JPEG copies sized below GitHub's 1 MB upload
  limit. Use these for the repository Social preview.
- `avatar-options/` — square crops for visual comparison only. The final
  organization avatar should use a simpler, exact token-ingot mark.

Options A–E correspond across all three directories:

- A: network grid
- B: layered horizon
- C: blueprint
- D: digital foundry
- E: data ribbons
